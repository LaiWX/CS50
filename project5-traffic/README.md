# 实验记录

## 首次实验
直接照搬 MNIST 的训练代码（更改输入形状和输出大小）
- 卷积核：32
- 池化：最大值
- 展平
- 隐藏层：128

效果很差，只有 35% 的正确率，loss 2.36
推测交通标志的结构比手写数字复杂很多，导致欠拟合

## 第二次实验
加大神经网络规模
- 卷积核：128
- 池化：最大值
- 展平
- 隐藏层：512

准确率达到 95%，loss 0.22
训练时间暴涨，从每步6ms提升到每步60ms

## 第三次实验
引入第二层卷积层，并缩小网络结构
- 卷积核：64
- 池化：最大值
- 卷积核：64
- 池化：最大值
- 展平
- 隐藏层：256

准确率达到 91%，loss 0.33
每步训练时间降回毫秒级

## 第四次实验
将池化改为平均值池化
- 卷积核：64
- 池化：平均值
- 卷积核：64
- 池化：平均值
- 展平
- 隐藏层：256

准确率提升至 98%，loss 0.08

## 第五次实验
缩减神经网络规模
- 卷积核：32
- 池化：平均值
- 卷积核：32
- 池化：平均值
- 展平
- 隐藏层：128

准确率和 loss 维持了 98%、0.08 的水平
